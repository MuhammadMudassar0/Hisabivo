# Noto Naskh Arabic

These are the full, static TrueType Regular and Bold fonts from the official
[Noto Naskh Arabic v2.021 release](https://github.com/notofonts/arabic/releases/tag/NotoNaskhArabic-v2.021).
The `full/ttf` files include Latin letters as well as Urdu and Arabic glyphs.
The narrower `hinted/ttf` release files omit Latin letters and are unsuitable for mixed English/Urdu reports.

Copyright 2022 The Noto Project Authors. Distributed under the bundled SIL Open
Font License 1.1 in `OFL-NotoNaskhArabic.txt`.

PDF helpers embed both weights under `NotoNaskhArabic`. Use per-text bidi options
for Urdu text rather than reversing the whole document, which would also reverse
English labels and numeric columns. This is a Naskh font, not Nastaliq.
